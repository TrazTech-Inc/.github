# TrazTech

Security and compliance consultancy based in Toronto, Canada. Founded by [Jacob Masse](https://jacobmasse.com) - published security researcher with 5 CVEs including [CVE-2024-45163](https://nvd.nist.gov/vuln/detail/CVE-2024-45163) (CVSS 9.1).

## What We Do

We help startups and growing companies get audit-ready and stay secure. Our services include:

- **Compliance** - SOC 2, ISO 27001, ISO 42001, HIPAA, PCI DSS, GDPR, PIPEDA
- **Security** - Penetration testing, cloud security, AI/LLM security
- **Fractional CISO** - Part-time security leadership for teams that need it

**Results to date:** Zero exceptions on SOC 2 Type II. 76 controls implemented. 75 days from kickoff to audit-ready. $11K saved on audit quotes.
